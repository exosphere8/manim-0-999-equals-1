# 0.999... = 1 — Manim Mathematics Short

A vertical mathematical animation demonstrating why the repeating decimal 0.999... is exactly equal to 1.

## Mathematical Concept

The animation explores the equality using two visual proofs:

1. **The fraction proof:** One third equals 0.333..., so multiplying both sides by three gives 1 = 0.999...
2. **The vanishing gap:** As more nines are added, the difference between the decimal and 1 approaches zero. The infinite repeating decimal has no positive gap remaining.

## Built With

- Python
- Manim Community Edition
- DaVinci Resolve
- ElevenLabs text-to-speech

## Run the Animation

Install Manim, then run:

```bash
manim -pqh main.py PointNineRepeating
```

The animation is configured for a vertical 1080 × 1920 canvas at 30 FPS.
